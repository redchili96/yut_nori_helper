# Privacy information — M2 Companion Yut Nori Helper (Beta)

## Local data

This website operates entirely in the user's browser. Games and settings are saved in `localStorage` on the browser/device where they were created. The current release does not include accounts, analytics, tracking pixels, external APIs or automatic log uploads.

## Exported files

Choosing JSON or CSV export saves a file to the user's device. Exports can contain gameplay events, timestamps, outcomes, a unique game ID and a random browser-level `sourceId`. The latter can link exports from the same browser; therefore exports are **pseudonymous, not guaranteed anonymous**. No Metin2 account username or email is requested by the helper.

Only share exported data voluntarily. Importing files from other people stores their match data locally on your own browser.

## Storage and removal

You can clear the helper's local browser data by clearing site data for the website in browser settings. If you export a log, its copies are controlled separately by whoever received the file. Switching domains or browsers does not automatically transfer history.

## Hosting

A static host may receive standard network request metadata (for example, IP address and browser headers) as part of serving the site. This is separate from the application's locally stored game history.
